# 🌤️ Weather App

A weather application built with **React**, **Tailwind CSS**, and **Axios**.

This is my **second Frontend Mentor challenge** and my **first real application built with React**. I built the application completely from scratch without following tutorials.

This project was an important step in my learning journey because I started using **React as my main technology** while working with real application state, API requests, reusable components, and asynchronous data.

---

## ✨ Features

| **Feature**                   | **Description**                                                     |
| ----------------------------- | ------------------------------------------------------------------- |
| 🔎 **City Search**            | Search for cities by name                                           |
| 💡 **Search Suggestions**     | Displays matching city suggestions while typing                     |
| 🌤️ **Current Weather**       | Displays the current weather for the selected city                  |
| 📅 **7-Day Forecast**         | Displays the weather forecast for the next 7 days                   |
| ⏰ **12-Hour Forecast**        | Displays hourly weather information for the selected location       |
| 🔄 **Request Cancellation**   | Cancels previous weather requests when a new request is made        |
| 🛡️ **Stale Data Prevention** | Prevents outdated API responses from overwriting newer weather data |
| 🧩 **Component Architecture** | Built using reusable React components                               |
| 📱 **Responsive Design**      | Works across mobile, tablet, and desktop screen sizes               |

## 📚 What I Learned

### ⚛️ Using React as My Main Technology

This project was my first real application built with **React**.

I started using React as my main technology and learned how to structure an application around **components, props, state, and effects**.

Building the application from scratch helped me understand how React can be used to manage the UI and application state as an application becomes more complex.

### 🧠 Application State Management

I learned how to manage application state across different scenarios and how different parts of the application depend on that state.

The application contains different states for things such as the selected city, search results, loading states, errors, and weather data.

### 🏗️ Component Architecture

This project gave me practical experience with building an application using a **component-based architecture**.

I learned how to break the application into smaller reusable components and how to make those components communicate through props and state.

This made the application easier to organize and maintain as more features were added.

### 🏗️ Maintainable & Scalable Code

I focused on making the code more maintainable and scalable by applying **Separation of Concerns**.

Different responsibilities are separated into appropriate components and functions, making the application easier to understand and modify.

### ♻️ DRY Principle

I tried to identify duplicated code and turn it into reusable functions, keeping the code as **DRY (Don't Repeat Yourself)** as possible.

### 🌐 Working With APIs

I gained practical experience working with external APIs and handling asynchronous requests.

The application retrieves location information and weather data dynamically based on the user's selected city.

### 🔄 Handling Asynchronous Requests

One of the more challenging parts of the project was handling multiple API requests.

I learned how **stale data** can become a problem when an older request finishes after a newer request.

To prevent this, I implemented **request cancellation** so that an older weather request can be cancelled when a new request is made.

### 🧩 Problem Solving & Edge Cases

This project gave me a lot of practical problem-solving experience.

I had to think about and handle different edge cases that could occur while the user interacts with the application, especially around searching, API requests, loading states, errors, and changing selected locations.
